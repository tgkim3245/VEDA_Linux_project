## 소개 
- VEDA 3기 학습과정 중에 따라 리눅스 시스템 프로그래밍 및 장치제어 학습 후 실습 평가과제 결과물입니다.
- 멀티프로세싱/스레딩, 시그널 등 리눅스 프로그래밍과 라즈베리파이를 통한 외부 장치(LED, 부저)등 제어를 다룹니다.
## 주요 기능
### ☐ (장치제어) 다양한 외부장치(LED, 부저 등)를 원격(client)에서 제어 
- LED /부저 : 3단계(최대, 중간, 최저) 밝기 및 음악(on/off) 조절 
- 조 도 센 서 : 조도센서 값 확인 및 빛의 여부로 LED 제어(on/off) 
- 7세그먼트 : 클라이언트에서 전송한 숫자(0~9) 카운트다운 후 부저 
- (추가) DC모터 : 조도센서 값에 따라 DC모터 속도 조절
### ☐ (동작환경) 멀티스레드, 동적라이블러리, 시그널 등 수업내용 실습 
- 멀티스레드 : 멀티스레드(혹은 멀티프로세스)를 통한 외부 장치 제어 
- 라이브러리 : 장치제어 프로그램은 동적 라이브러리 형식 
- 시그널 처리 : 클라이언트는 SIG_INT 제외 모두 무시 처리
- Daemon 서버 : 서버 실행 시 백그라운드에서 Daemon으로 동작 
- 빌드자동화 : Makefile을 통한 빌드 자동화

### 빌드 방법
#### 빌드
```
git clone https://github.com/tgkim3245/VEDA_Linux_project.git
cd VEDA_Linux_project
make
```
#### 서버
```
# 서버는 대몬 프로세서로 동작합니다.
./server
```
#### 클라이언트
```
./client
```
